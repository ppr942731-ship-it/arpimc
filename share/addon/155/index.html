Hotbar Slot Button

Paket sumber daya ini menambahkan tombol baru yang berfungsi seperti hotbar. Setiap tombol mengubah item yang dipegang tergantung pada tombol yang ditekan, misalnya, tombol 1 akan menekan hotbar 1, dan seterusnya. Tombol-tombol ini juga mendukung mode 2 jari! Ini berarti, misalnya, jika saya sedang menambang dan menggunakan beliung untuk menambang batu, dan kemudian tiba-tiba muncul kerikil, saya tidak perlu mengangkat jari saya dari layar untuk mengganti alat; saya cukup menekan tombol untuk mengganti alat dan melanjutkan penambangan. Anda juga dapat menyesuaikan posisi dan ukuran tombol! Anda perlu membuka panel Editor dengan menekan tombol roda gigi di kanan bawah layar. Setelah panel Editor muncul, Anda dapat menggunakan penggeser untuk memindahkan dan mengubah ukuran tombol.

Buka di ArpiMC ZoneAnda akan diarahkan otomatis dalam beberapa detik.
