DoubleHands - Functional Offhand like Java edition (MCPE PC etc)

DoubleHands adalah addon Minecraft Bedrock revolusioner :) yang dirancang untuk menghadirkan kesamaan penggunaan tangan kiri dengan Java Edition ke dunia Anda. Jika Anda pernah bertanya-tanya bagaimana cara menggunakan obor di tangan kiri Anda di Bedrock atau ingin meletakkan blok sambil memegang alat, inilah solusinya. Tidak seperti mod kosmetik dasar, addon tangan kiri fungsional ini memungkinkan Anda untuk memegang dan menggunakan item di tangan kiri Anda persis seperti di Java Edition. Kompatibel dengan Minecraft Bedrock 1.21+ , mod ini berfungsi sempurna di Realms, Dedicated Server (BDS), dan dunia pemain tunggal . Baik Anda membutuhkan mod untuk pertempuran atau senjata tambahan untuk menambang, DoubleHands memberikan pengalaman yang lancar dan tanpa lag bagi pemain seluler, konsol, dan PC.

Buka di ArpiMC ZoneAnda akan diarahkan otomatis dalam beberapa detik.
