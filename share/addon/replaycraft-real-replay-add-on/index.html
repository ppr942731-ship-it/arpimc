ReplayCraft Real Replay Add-on

ReplayCraft adalah add-on Minecraft Bedrock Edition yang canggih yang memungkinkan pemain untuk merekam dan memutar ulang aksi mereka di dalam game, mirip dengan ReplayMod yang populer untuk Java Edition. Baik Anda ingin merekam bangunan terbaik Anda, atau membuat tayangan ulang sinematik, ReplayCraft memudahkan Anda untuk merekam, memutar ulang, dan menganalisis permainan langsung di dalam Minecraft Bedrock Edition. ReplayCraft kini menggunakan API server 2.5.0-Beta dan API server-ui 2.1.0-Beta , yang meningkatkan kompatibilitas dan performa untuk Minecraft Bedrock.

Buka di ArpiMC ZoneAnda akan diarahkan otomatis dalam beberapa detik.
