ArpiMC Zone - Info Center Update

Basis pengerjaan: ArpiMC-Zone-Revisi.zip terakhir yang tersedia pada percakapan.

Pembaruan:
- Menu Info kini memiliki dua tab: Tutorial dan About ArpiMC.
- Tutorial menjelaskan cara menggunakan koleksi Skin, Addon, Game/Tools, membagikan konten, dan memasang PWA.
- About ArpiMC Zone diperbarui dengan pengenalan website, fokus konten, cara kerja fitur, kebijakan informasi, dan disclaimer independensi dari Mojang/Microsoft.
- Link saluran, media sosial, website/layanan, dan dukungan tetap diambil dari data.json serta ditampilkan pada tab About ArpiMC.
- Konten tutorial dan about disimpan di data.json agar mudah diperbarui.
- Service worker cache dinaikkan agar aset Info baru tidak tertahan cache lama.
- Identitas domain, SEO title, meta description, canonical, struktur skin/addon/game, dan routing lain dipertahankan.

Deployment:
Unggah seluruh isi ZIP ke root hosting. Pastikan file index.html, style.css, script.js, seluruh JSON, manifest.json, ikon, sw.js, vercel.json, _redirects, dan CNAME berada sesuai struktur. Gunakan HTTPS.

Catatan:
Pembaruan ini mengubah halaman Info dan data penjelasannya. Konten yang berasal dari situs pihak ketiga tetap bergantung pada ketersediaan layanan tersebut.
